## 説明文（プロモーション用テキスト・4000文字以内の要約）

**見出し**
- 広告が一切ない、シンプルな筋トレ記録アプリです。
- 起動から記録まで最速。前回の重量・回数がすぐ見えます。
- iCloudでデータを守れます。CSVエクスポートも可能（プレミアム）。

**差別化**
- 記録画面で常に「前回値」「PR」を表示。+2.5kg / +1rep のクイックボタンで入力が少ない。
- 種目別の進捗グラフ（最大重量・ボリューム）、週次ボリュームを部位別に表示。
- 構造化メモタグ（フォーム崩れ・痛みなど）で次回に活かせます。
- 休憩タイマー・Apple Watch連携（プレミアム）。買い切り課金で広告なしを維持。

**ストア用スクリーンショット推奨**
1. 記録画面（前回値・PR・クイックボタンが映る）
2. 進捗グラフ（最大重量の成長線）
3. ホーム（今週サマリ・直近履歴）
4. Apple Watch画面
