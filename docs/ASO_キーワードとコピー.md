# らくらく筋トレ記録 — ASO（App Store 検索最適化）用コピー

App Store Connect の **プロモーション用テキスト / サブタイトル / キーワード / 説明** にそのまま貼れるよう設計。  
（「AEO」＝検索で上位に出す意図なら、ストアでは一般的に **ASO** と呼びます。）

---

## ASO で狙うこと（設計の考え方）

| 観点 | 方針 |
|------|------|
| **検索クエリ** | 日本で多い「筋トレ」「記録」「ワークアウト」「ジム」「PR」「グラフ」「ルーティン」「Watch」などをキーワード欄に配置（アプリ名に含まれる語は**繰り返さない**）。 |
| **タイトル周り** | **名前・サブタイトルは検索に効く**ので、サブタイトルに機能・ベネフィットを詰める。 |
| **キーワード欄** | **100 文字まで・カンマ区切り**（カンマの後にスペースは入れないと文字数の節約になる）。アプリ名と**重複する語は無駄**なので入れない。 |
| **説明文** | 先頭 2〜3 行が一覧・検索のプレビューで効く。**機能名＋ユーザー利益**を自然文で織り込む（キーワードの詰め込みすぎは読みにくいだけ）。 |
| **プロモーション用テキスト** | **審査なしで何度でも更新可能**（仕様は App Store Connect のヘルプを確認）。キャンペーン・季節・新機能の告知向き。 |
| **実装との整合** | 無料版ではワークアウト完了タイミングなどに**広告が出る場合あり**。**プレミアム買い切りで広告非表示**。ストア文面は誇大表現を避ける。 |

---

## コピペ用ブロック（日本語）

### 1. プロモーション用テキスト（170 文字以内）

**推奨（121 文字）** — そのまま貼り付け可。

```
前回の重量・回数とPRがすぐ見える筋トレ記録。セット入力のショートカット、部位別グラフ、ルーティン、休憩タイマー、Apple WatchやHealthKit連携も。データはiCloudで端末間同期。プレミアム買い切りで広告を非表示にできます。
```

**短め案（71 文字）** — キャンペーン用に余白を残したいとき。

```
前回値・PR表示で記録が速い筋トレログ。グラフ・ルーティン・休憩タイマー・Watch対応。iCloud同期。プレミアムで広告オフ（買い切り）。
```

---

### 2. サブタイトル（30 文字以内）

App Store の **サブタイトル** 欄用。**1 行だけ**貼る。

**推奨（29 文字）**

```
筋トレ記録・前回値とPR・グラフ・Watch
```

**代替案**

| 案 | 文字数目安 | 文言 |
|----|------------|------|
| A | 28 | 記録が速い筋トレログ iCloudグラフWatch |
| B | 30 | 筋トレ記録｜ルーティン・統計・タイマー・同期 |
| C | 27 | ワークアウト記録 PRグラフ ルーティン Watch |

---

### 3. キーワード（100 文字以内・カンマ区切り）

**メイン案（98 文字）** — カンマの直後にスペースなし。残り 2 文字は運用で微調整可。

```
筋トレ,トレーニング,ワークアウト,記録,ジム,重量,PR,グラフ,ルーティン,Watch,HealthKit,iCloud,統計,ベンチ,スクワット,デッド,ボリューム,休憩,タイマー,トレログ
```

**代替案（99 文字）** — 「回数・セット・デッドリフト」寄り。

```
筋トレ,記録,ワークアウト,ジム,重量,回数,セット,PR,グラフ,統計,ルーティン,Watch,HealthKit,iCloud,ベンチ,スクワット,デッドリフト,ボリューム,休憩,タイマー,成長
```

**入れない方がよいものの例**

- アプリ名に既にある語の繰り返し（「Kintore」など）
- 他社アプリ名・誤認を招く固有名（審査リスク）
- 空白だけの区切り（公式は **カンマ区切り** が一般的）

---

### 4. 説明（概要・説明フィールド用・4000 文字以内）

**そのまま貼れる長文ドラフト**（先頭がストアの「もっと見る」前に効くようにベネフィット先行）。

```
らくらく筋トレ記録は、ジムや自宅トレの「重量・回数・セット」を素早く残せる筋トレ記録アプリです。記録画面では前回の記録やPR（自己ベスト）を常に確認でき、入力の手間を減らす操作にこだわりました。

【こんな人向け】
・毎回メモアプリやスプレッドシートで管理するのが面倒
・前回どれくらい上げたか、すぐ見たい
・種目ごとの成長や週のボリュームをグラフで振り返りたい
・ルーティンで同じメニューを繰り返したい
・Apple Watchでタイマーや記録まわりを使いたい

【主な機能】
・ワークアウト記録（種目・セット・重量・回数）
・前回値・PRの表示、入力の補助
・統計・グラフ（種目や部位の傾向の把握）
・ルーティン作成
・休憩タイマー
・Apple Watch 対応
・Apple Health 連携（設定に応じて）
・データのバックアップ・同期（iCloud 利用時）

【プレミアム（買い切り）】
広告を非表示にできます。その他の主要機能は無料でお試しいただけます。

【注意】
本アプリの利用にはインターネット接続が必要な場合があります。HealthKit や iCloud を使う機能は、それぞれ OS の設定と権限が必要です。
```

必要に応じて、**実装に合わせて**「CSV エクスポート」「メモタグ」など追記してください（実機の機能一覧とズレないようにするのが審査・評価で有利です）。

## ストア用スクリーンショット（掲載順の推奨）

1. 記録画面（前回値・PR・クイック操作が分かる）
2. グラフ・統計（成長が伝わる）
3. ホーム（継続のしやすさ）
4. Apple Watch（対応アピール）

### Watch（プレミアム画面）を課金なし・シミュレーターで撮る（開発者向け）

Watch の待機画面は非プレミアムだと案内文のみ。**Debug ビルド**だけ、次のいずれかでプレミアムと同じ UI（`WatchSessionView`）を出せます。**App Store 提出用アーカイブ（Release）には含まれません。**

1. **Watch 用スキームで実行する場合**（または Watch 実行に引数が届く場合）  
   **Product → Scheme → Edit Scheme → Run → Arguments → Arguments Passed On Launch** に  
   `-ScreenshotPremium`  
   を追加。実行先を **Apple Watch Ultra 3** などのシミュレーターにする。

2. **引数が Watch に届かないとき**（いまの `Kintore` スキームは iPhone 向けのため、Watch 単体では届かないことがある）  
   **Run → Arguments → Environment Variables** に  
   `SCREENSHOT_PREMIUM` = `1`  
   を追加（**Watch 拡張がターゲットのスキーム**で設定するか、下記 `simctl` を使う）。

3. **ターミナルから Watch アプリだけ起動**（例・Bundle ID はプロジェクトと一致させる）  
   `xcrun simctl launch <WatchシミュレータのUDID> com.shunsukesaito.kintore.watchkitapp -ScreenshotPremium`

PR 行のダミー文言は `watch_screenshot_demo_pr`（ローカライズ）です。撮影後はスキームの引数・環境変数を外す。

## 更新メモ

- キーワードは **検索トレンドに合わせて数ヶ月ごと**見直すと効果が出やすいです（変更は新バージョン申請が必要な場合があるため、Connect の最新ヘルプを確認）。
- **プロモーション用テキスト**は比較的すぐ更新できるため、新機能リリース・キャンペーンに合わせて差し替え可能。
