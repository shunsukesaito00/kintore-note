Kintore Note（キントレノート）— サポート

筋トレ・ワークアウトの記録を行う iOS アプリです。以下の方法で、ご質問・不具合のご連絡・ご要望をお送りいただけます。

お問い合わせ・サポートの方法

  • 不具合（バグ）の報告：バグ報告フォーム（GitHub）
  • 機能のご要望：機能要望フォーム（GitHub）
  • 既存の報告の一覧：GitHub Issues

GitHub アカウントが必要です。アカウントをお持ちでない場合は、無料で作成できます。

よくある質問（FAQ）

  • データはどこに保存されますか？ 端末内に保存されます。プレミアムで iCloud 同期を利用する場合は、Apple の iCloud に保存されます（設定に従います）。
  • プレミアムの購入・復元は、iPhone の「設定」アプリ内の Kintore Note から、またはアプリ内の設定画面から行えます。購入に問題がある場合は、上記フォームからお知らせください。
  • 返信について：内容を確認のうえ、可能な範囲で対応します。個人開発のため、即日の返信をお約束できない場合があります。

ご注意

  • Issue やフォームには、パスワードや個人を特定しやすい情報を書かないでください。
  • 本アプリは医療機器ではありません。健康上のご判断は医師等の専門家にご相談ください。
